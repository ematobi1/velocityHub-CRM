## 🚀 Quick Start

### **Prerequisites**
- Node.js v18+
- MongoDB
- Redis
- Docker (optional)

### **Environment Variables**

#### Backend (.env)
```bash
# Server
PORT=5001
NODE_ENV=development

# Database
MONGODB_URI=mongodb://localhost:27017/velocityhub
REDIS_URL=redis://localhost:6379

# Authentication
JWT_SECRET=your-secret-key-min-32-chars-long

# OpenAI
OPENAI_API_KEY=sk-your-openai-key

# Twilio (WhatsApp/SMS/Voice)
TWILIO_ACCOUNT_SID=your-twilio-sid
TWILIO_AUTH_TOKEN=your-twilio-token
TWILIO_PHONE_NUMBER=+1234567890
TWILIO_WHATSAPP_NUMBER=whatsapp:+1234567890

# DocuSign
DOCUSIGN_INTEGRATION_KEY=your-integration-key
DOCUSIGN_USER_ID=your-user-id
DOCUSIGN_ACCOUNT_ID=your-account-id
DOCUSIGN_PRIVATE_KEY=path/to/private.key

# Stripe
STRIPE_SECRET_KEY=sk_test_your-stripe-key
STRIPE_WEBHOOK_SECRET=whsec_your-webhook-secret

# Lead Generation APIs
APOLLO_API_KEY=your-apollo-key
ZOOMINFO_USERNAME=your-username
ZOOMINFO_PASSWORD=your-password

# Media Storage
CLOUDINARY_CLOUD_NAME=your-cloud-name
CLOUDINARY_API_KEY=your-api-key
CLOUDINARY_API_SECRET=your-api-secret

# Frontend URL
FRONTEND_URL=http://localhost:3000
```

#### Frontend (.env)
```bash
REACT_APP_API_URL=http://localhost:5001/api
REACT_APP_SOCKET_URL=http://localhost:5001
```

### **Local Development**

```bash
# Clone repository
git clone https://github.com/YOUR_USERNAME/velocityhub-crm.git
cd velocityhub-crm

# Start databases (Docker)
docker-compose -f docker-compose.dev.yml up -d

# Backend setup
cd backend
npm install
npm start
# Runs on http://localhost:5001

# Frontend setup (new terminal)
cd frontend
npm install
npm start
# Runs on http://localhost:3000
```
